# ⚡️ Sticker to GIF Converter

A modern web application to convert animated stickers (APNG) to high-quality looping GIFs and extract static PNGs.

🌐 **Web App**: [https://louis-369.github.io/sticker-to-gif/](https://louis-369.github.io/sticker-to-gif/)

---

## ✨ Features

- 🔄 **APNG to GIF**: High-quality conversion with transparent backgrounds and infinite looping.
- 🖼 **Static Extraction**: Direct download of crisp, lossless PNG images.
- ⚡️ **Single & Batch**: Instant one-click single item conversion or full batch ZIP packaging.
- 📱 **Mobile Optimized**: Responsive web interface designed for both desktop and mobile browsers.

---

## 🛠 Tech Stack

- **Frontend**: HTML5, Tailwind CSS, JavaScript (Hosted on GitHub Pages)
- **Backend**: FastAPI, Python (Hosted on Hugging Face Spaces)
